# 衡水湖烤鸭蛋 · 湖小鸭 ｜ 特色农产品及衍生品方案设计

课程任务「特色农产品及衍生品的方案设计-2：设计带数据库的网页与 3D IP 形象」交付站点。
线上地址：https://meng12346d.github.io/ ｜ 第 8 组：孟泽霏、宋晓雨

## 任务要求对照

| 任务要求 | 实现情况 |
|---|---|
| 1. 内容管理后台 | 页脚「后台管理」入口（密码 `admin123`），可管理预定订单（办结/删除/导出CSV）、溯源批次（新增/删除）、产业账本（录入/删除）、成本与零售价编辑、收集卡统计 |
| 2. 收集卡 | 「收集卡」板块：5 款湖小鸭卡牌抽卡收集，记录写入数据库；后台可看抽卡统计与明细，支持清空 |
| 3. 溯源设计图片 | 溯源板块配真实产品图（礼盒/产品实拍图），批次码可查询全链路 8 道工序 |
| 4. 3D IP 形象 | 「3D打印」板块：模型渲染图 + `huxiaoya.stl`（105,024 面，可直接切片打印）+ `huxiaoya.glb` 源文件下载，附打印参数建议；STL 即 STEP 的替代交付格式（网格转 STEP 可在 CAD 中完成） |

## 数据库说明

数据层基于浏览器 `localStorage`（键前缀 `hsy_`），表：orders（预定订单）、batches（溯源批次）、
ledger（账本）、costs/price（成本）、draws（抽卡记录）、myCards（收集册）。后台支持订单导出 CSV。

## 文件结构

- `index.html` — 主站（品牌故事 / 品牌IP / 3D互动 / 3D打印资产 / 收集卡 / 产品 / 溯源 / 账本 / 购买合作 / 管理后台）
- `model.html` — 湖小鸭 3D 互动查看器（three.js + GLB 内联）
- `assets/` — 图片素材、huxiaoya.glb、huxiaoya.stl
